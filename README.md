# Preventive Maintenance Dashboard

A maintenance analytics dashboard designed to monitor preventive maintenance performance, PM compliance, overdue tasks, maintenance costs, job completion, and reliability trends.

## Dashboard Preview

![Preventive Maintenance Dashboard](./Preveventive%20Maintenance%20Dashboard%20Image.jpeg)

## Project Overview

This dashboard provides a centralized view of preventive maintenance activities and performance. It combines maintenance workload, compliance, overdue task analysis, cost monitoring, and completion trends to support maintenance planning and performance evaluation.

## Dashboard Structure

The dashboard is organized around the following areas:

1. **Maintenance Overview** — Total PM jobs, compliance, overdue tasks, and completion time.
2. **Planned vs Completed Jobs** — Comparison of scheduled maintenance activities against completed jobs.
3. **PM Adherence** — Visualization of planned, completed, and overdue maintenance activities.
4. **Overdue Task Breakdown** — Period-wise analysis of overdue maintenance work.
5. **Cost Analysis** — Comparison of planned and actual maintenance costs.
6. **Compliance Trend** — Monitoring PM compliance performance over time.

## Purpose

The objective of this dashboard is to provide a centralized view of preventive maintenance performance, helping management monitor compliance, identify overdue activities, evaluate maintenance costs, and track execution trends.
